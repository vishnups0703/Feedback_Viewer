# Feedback Launch

A real-time, interactive presenter tool designed to display live audience feedback progress using an animated rocket mascot launch. 

## What It Does
* **Live Progress Tracking:** Monitors audience submissions dynamically and updates an on-screen display.
* **Animated Mascot Payoff:** Visualizes progress through escalating tension animations as responses come in, culminating in a dramatic rocket launch sequence once the goal is reached.
* **Presenter Setup & Display Modes:** Includes a dedicated setup page for presenters to configure parameters before launching the audience-facing display.

## Flexibility & Configuration
To make the tool as versatile as possible across different event sizes and setups, it includes:
* **Custom Sheet & Form Integration:** Direct options to link your own Google Sheet (for live tracking) and Google Form (auto-generated into an on-screen QR code for participants to scan).
* **Flexible Target Goals:** Simple settings to specify the total number of expected participants or feedback responses required to trigger the completion launch.
* **Display Modes:** Choose between displaying progress as a percentage or as a direct count (e.g., `4 / 10`), along with built-in demo mode for dry runs.
